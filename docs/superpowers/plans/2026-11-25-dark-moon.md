# Dark Moon expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the Dark Moon expansion: mana 10/15, text that fits, flowing aim arrow, packs with followers, Dark Moon, stealing, changed copies, history, new ops/conditions, ~80 cards, deck 6, AI, balance and visuals.

**Architecture:** Rules stay in `core/` (pure, headless-testable, deterministic for online lockstep). Followers use *spots*: a player's creature spots are 0..7, spot `k` lives in lane `k % 4` (0..3 main, 4..7 followers), so every existing `{player, lane}` reference, Action field and network message keeps working with the lane value read as a spot. Changed copies are runtime CardData duplicates with `base_id`. View work in `view/`, AI in `ai/`.

**Tech Stack:** Godot 4.7.2, GDScript, headless suite `godot --headless --path . --script res://tests/run_tests.gd [-- --only=x]`.

**Spec:** `docs/superpowers/specs/2026-11-25-dark-moon-design.md`

Native, self-approved (user's standing preference). Ledger `.superpowers/sdd/2026-11-25-dark-moon/progress.md` (rulings, card sheet, numbers). Restamp rules (`tools/stamp_rules.gd`) after core changes. Commit per task. No push, no web export unless asked.

## Global Constraints

- `MAGIC_CAP = 10`, `MAGIC_CAP_MAX = 15`.
- Only pack cards fill follower spots; normal creatures need an empty lane; merging only on main spots.
- Legendary: max 1 copy per deck. Neutral cards deck-legal except Star Shard. 40-card decks only with an `allows_40` card.
- Every effect must render on Mobile and Compatibility; HD 620 Low drop ≤ ~2 fps on a full board.
- Online digest must cover changed copies, followers and history.
- All decks 40–60% win rate in sims.

## Review Focus

- Dark Moon with followers and with a unit crossing into a side whose creatures are all frozen/ready: owner flips, can't attack this turn, digest equal on both peers.
- Leader dies while follower lives, in the same `resolve_deaths` pass as a Last Breath summon into that lane: follower moves to the main spot first; the summon then fails (lane full) without error.
- Changed copy merged / bounced / stolen / returned from discard: identity checks use `base_id`; VisualDB and card art still find the model.
- Replay/echo loops: Frost replay replaying itself or a card that replays; echo + Dream Up opening two picks; must not recurse or deadlock (replay skips replay cards; second pick waits for the first).
- Text fit at the smallest card size for the longest legendary text and for Dark Gift copies with the extra line.
